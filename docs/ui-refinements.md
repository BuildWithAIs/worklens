# 界面调整 · 2026-09-09

按用户截图反馈覆盖原 PRD 中对应的首次使用与展示要求：

- 移除本地工具确认弹窗、首次使用提示和主进程发送拦截。旧设置中的 `riskAccepted` 字段兼容保留，但不再影响发送。
- 主页顶部移除模型配置栏及本地工具就绪标识；保留会话标题和运行状态。默认模型继续在设置页配置。
- 侧边栏底部移除本地保存提示和“模型与偏好”，保留设置按钮。
- 设置页本地数据卡片只保留四组目录信息，移除下方说明段落。

不改变 Pi 工具执行、凭据存储或系统提示词。

## 历史列表与空白对话区

- 历史列表继续展示 Pi 发现的全部会话，不按月份或数量裁剪；每条会话提供常驻的重命名与删除按钮，点击正文打开完整历史。
- 空列表明确显示“暂无历史会话”，避免占位文案看起来像不可点击的历史项。
- 空白对话内容仅保留“一点想法，一起完成”和“今天，我们从哪里开始？”。
- Electron 实测覆盖历史点击、续聊、重命名与重启恢复，以及删除另一条会话不影响当前会话。
- 正式版与开发版数据保持隔离；此次只统计本机记录数量，未复制或修改用户会话。正式版目录有一条记录，开发版目录为空。

## 消息身份标识

- 用户消息使用圆形默认人物头像，固定在消息气泡右上角，正文预留空间避免重叠；支持浅色和深色主题。
- 移除用户消息左上角的“你”字，保留头像的辅助阅读标签；WorkLens 左上角标识保持原样。
