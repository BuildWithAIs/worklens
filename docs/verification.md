核心测试 **17 项通过**，桌面测试包含开发版闭环、崩溃恢复及打包实测三项，类型检查和生产构建通过。额外覆盖 `read/ls/find/grep/edit` 实际文件操作和损坏 JSONL 不影响有效会话。20 轮并发包含实际文件写入，30 次恢复也验证工具历史。Windows NSIS 安装包约 122 MiB，未签名。打包运行时实测为 Electron 42.11.2 / Node 24.19.0。本机安装测试不等同于干净虚拟机验收。

脱敏补测：包含引号、反斜杠和换行的凭据及其 JSON 转义形式均被隐藏；纯数字凭据不会破坏数字耗时字段，认证类型、布尔值和空值保持原类型。最新开发版 Electron 闭环同时通过，启动测量为 1961 / 1934 毫秒。

命令补测：Pi 原生 PowerShell 正常执行返回实际退出码 0，`exit 7` 显示失败及退出码 7，超过 0.1 秒限制的休眠命令显示“已超时”。这些结果由真实进程产生；命令初始目录、超时设置和成功退出码也纳入安装包界面检查。

凭据恢复补测：启动前向临时账户写入损坏凭据文件，确认设置页可打开并显示服务商级诊断；原文件在用户重新配置前保持不变。通过 Pi 认证界面提交替代测试密钥后，错误消失，系统加密的新凭据可读取，磁盘及常规 IPC 不出现明文密钥。该流程已通过单元和真实 Electron 测试。

桌面并发测试额外延迟会话 A 的模型可用性检查，在 A 尚未返回发送确认时创建并发送 B，确认 B 仍能完成、界面不会被 A 的迟到确认强制切回；停止 A 不影响 B。

## 发布前仍需外部条件的验收

- 真实 API Key、OAuth/设备码、环境凭据服务商的完整账号矩阵。
- Azure 自定义部署实例上的文本与工具请求。
- macOS Apple Silicon 实机 Bash、Keychain、打包和安装；Intel 是否同期发布。
- Windows 与 macOS 干净环境安装、升级、卸载保留数据。
- 发行代码签名和 macOS 公证；五名试用用户与二十个真实用户任务。
- GitHub Copilot 企业域名专项验证（PRD 明确不阻塞第一版）。

这些项目没有真实验证证据时不得勾选完成，也不得给服务商加“WorkLens 已验证”标签。
