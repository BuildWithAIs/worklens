# 国际化

桌面界面使用 `i18next`、`react-i18next` 和 `i18next-browser-languagedetector`。当前支持英文（`en`）和简体中文（`zh`），默认使用英文；用户选择保存在 `worklens.language`，重启后恢复。

## 目录与职责

- `src/renderer/src/i18n/index.ts`：初始化语言检测、回退语言、React 集成和 HTML `lang` 属性。
- `src/renderer/src/i18n/locales/en.ts`：英文基准资源及翻译 key 的类型来源。
- `src/renderer/src/i18n/locales/zh-CN.ts`：简体中文资源。
- `src/renderer/src/lib/system-text.ts`：只翻译已知的应用系统消息，不改写用户、Agent 或工具内容。

组件通过 `useAppTranslation()` 取得 `t` 和规范化后的 `language`：

```tsx
const { t } = useAppTranslation();

return <Button>{t("common.save")}</Button>;
```

翻译 key 按功能域组织，并使用插值表达完整句子。不要在组件中并排传入中英文，也不要拼接依赖语序的句子：

```tsx
t("app.conversationOptions", { title: conversation.title });
```

新增界面文案时，必须同时补充英文和简体中文资源。`tests/i18n.test.ts` 会检查两种语言的 key 集合一致，并覆盖语言归一化、切换、插值和系统消息翻译；`tests/e2e/i18n.spec.ts` 会在真实 Electron 中验证即时切换与重启恢复。
