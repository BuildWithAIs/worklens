# WorkLens welcome & identity study 01

Independent visual prototype; not wired into the Electron app or backend.

- `index.html`: white welcome screen and three switchable identity directions.
- `logo-focus.svg`, `logo-lens.svg`, `logo-fold.svg`: original editable monochrome logo concepts.
- Existing WorkLens neutral colors and system typography; subtle green welcome accent.
- Scenario cards fill an editable draft. No model calls, uploads, or filesystem operations.
- Intended production composition: existing shadcn Card, Carousel, Button and Input primitives, existing composer.
- Branding and capability copy are proposals for review, not production changes.

Run `python3 -m http.server 4311 --directory designs` from the repository root.
Open http://localhost:4311/worklens-welcome-v1/.
